Important statesThese sketches show a ready, returning user. A first-time user should see setup guidance instead of empty statistics; an unavailable microphone or model should replace “Ready” with a clear fix. During a recording, show the live status and a Stop action. Show recovery for failed speech when relevant.
These are layout concepts, not working controls or real user data. The figures, shortcuts and recent items are illustrative. Both directions use the app’s existing Paper & Ink visual language; final spacing and components should be tested with keyboard and VoiceOver.
